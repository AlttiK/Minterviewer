Privacy Policy - Minterviewer

Last updated: March 22, 2026

Overview

This extension does NOT collect, store, or transmit any personal data to external servers.

Data Collection

This extension does not collect any personal information, analytics, or usage data.

Local Storage

The following data is stored locally on your device using Chrome's storage API:

  • Interview conversation history
  • Current session state
  • LeetCode problem descriptions (temporarily cached)

All data remains on your device and is never transmitted to external servers except your local backend (localhost:8000).

Third-Party Services

The extension communicates with:

  • Local Backend: A FastAPI server running on localhost:8000 (user-controlled)
  • LeetCode.com: Only to read problem descriptions from pages you visit

No analytics, tracking, or external data transmission occurs.

Permissions

The extension requests the following permissions:

  • storage: Save interview progress locally
  • tabs: Open problem pages
  • activeTab: Read problem descriptions
  • sidePanel: Display interview interface
  • scripting: Extract problem text and context from pages

Data Security

All conversation data is stored locally in your browser. You can clear this data at any time by:

  • Clicking "Return to Home Page" after an interview
  • Uninstalling the extension
  • Clearing Chrome's browsing data

Changes to Privacy Policy

Any updates to this policy will be reflected in the extension's GitHub repository and Chrome Web Store listing.
